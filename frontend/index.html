Offline-First Architecture & P2P Relay Architecture Simulation Engine

In disaster zones, remote regions, or cellular outages, internet connectivity fails. VEYRA solves this by enabling offline devices to compose cryptographically tamper-proof transaction messages, gossip them over local peer-to-peer Bluetooth Low Energy (BLE) relays, and settle automatically once any peer encounters an internet-connected bridge.

1. Offline Client
Signs & seals AES-256 payload with RSA envelope.
2. BLE Gossip
Hops across untrusted peer nodes with TTL limits.
3. Bridge Uplink
4G/Wi-Fi connected gateway forwards to VEYRA API.
4. Settlement
Java verifier unpacks, deduplicates, settles ledger.

Bridge Node Gateway & Ledger Synchronizer

When phone-bridge detects internet connectivity, it uploads buffered encrypted packets to the VEYRA PHP API. The PHP Gateway calls the Java Verification Microservice to decrypt with RSA private key, verify SHA-256 hash digests, enforce two-tier idempotency (dropping duplicate copies received through divergent mesh paths), and atomically update account balances.
